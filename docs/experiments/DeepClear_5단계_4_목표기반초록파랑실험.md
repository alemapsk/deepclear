## 3. 발견
1. **목표 방식이 0689와 탁한 물의 모순을 방향상으로는 푼다.** 0689에서는 wp를 1.0보다 올리고(Dive+ 쪽으로 파랑), 탁한 물에서는 내린다. 고정 wp로는 불가능했던 것.
2. **그러나 초록이 강한 물에서는 wp 0에서도 목표에 못 미친다.** 232212·225438은 wp 0에서도 물이 회색·회올리브(a* −6~−11)로, 원본 초록의 50%(a* −18)보다 더 중립 쪽이다. → **이 장면들을 중립까지 끄는 주된 힘은 초록→파랑이 아니라 화이트밸런스(색온도·틴트)다.** 그래서 B·C·D가 같은 결과가 됨. 초록→파랑 손잡이만으로는 Dive+의 청록(−16.5)에 도달 못 함.
3. **OI000249 블루워터의 물 마젠타(+5)는 wp와 무관** (wp 0에서도 +5.2). 역시 화이트밸런스 쪽.
4. **새 영상 프레임(MAH05095·MAH05094)에서 A는 바닥 모래·산호가 연보라·회청으로 차갑고, B·C는 청록 물 + 따뜻한 바닥으로 자연스러워 보인다**(e4_target_2.jpg). D는 그 사이. 이 장면들은 기존 29장보다 초록이 강해서(물 a* −26~−31) 지금 STRONG의 약점이 가장 크게 드러난다.
5. **E(hard clamp)는 국소적이고 안전한 편:** 마젠타로 넘어간 곳만 바뀜(232212 +2.8 → −1.4, 225438 +1.5 → −2.6, IMG_0048 +2.1 → −1.7). 물 얼룩(표준편차) 변화 없음. 다만 마젠타로 안 넘어간 연보라(MAH05095 바닥, a* 음수인데 b*가 크게 음수)는 못 고침. 클리핑 +1%p 넘은 사진 1장(P7134924 수영장 36.6 → 38.4%).
6. **B·C·D의 부작용:** 같은 영상의 프레임마다 wp가 0~0.375로 달라짐 → 영상에서는 SceneTracker 평활 필요, 프레임 간 흔들림 위험(6단계 측정). 일부 영역 얼룩 증가(DSC01490 잠수복 a* 표준편차 2.9 → 8.6, 잠수복 일부만 초록이 남음). 클리핑은 줄어듦(중앙값 2.9 → 1.2%, +1%p 넘은 사진 0장).
7. 피사체·중립 물체: B·C·D에서 DSC01282 모래 b* 12.9 → 18.8(Dive+ 19.1), IMG_0033 탱크 덜 파람(b* −24.4 → −20.9), 0689 거북 변화 작음(bgG 덕). Dive+ 거리 평균 A 28.6 → B 27.2 / C 27.1 / D 27.4 / E 27.6.

## 4. 결론과 제안 (미확정)
- **고정 잔존율 하나(50% 등)는 정답이 아님** — 초록이 강한 물에서는 wp 손잡이가 0에서 바닥나서 B·C·D 구분이 안 됨.
- **E(hard clamp)는 "마젠타로 넘어가지 않기" 안전장치 후보**로 유지 제안(비용 작음, 부작용 작음, 수영장 클리핑 1장 확인 필요).
- **탁한 초록 물의 회색·연보라 근본 원인은 화이트밸런스의 물 목표**로 보임 → 다음 실험 제안: wp는 고정(A 또는 E)하고, **화이트밸런스가 물 픽셀을 중립까지 끄는 양**(틴트·색온도의 물 비중)을 목표 기반으로 제한. 이전 tint 감쇠 실험은 wp 1.0과 같이 걸려 효과가 가려졌을 가능성.
- 장면 목표 wp(B·C·D)는 0689 방향은 맞지만, 영상 흔들림과 분석 비용 문제가 있어 화이트밸런스 실험 뒤 다시 판단.
