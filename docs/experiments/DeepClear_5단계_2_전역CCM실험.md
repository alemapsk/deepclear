## 1. 실험한 CCM의 정의
v1.16.1의 **빨강 복원(rc, 픽셀별 carrier) + 블루워터 앞단**을 사진당 3×3 행렬 하나로 바꾼다. 색온도·틴트·초록→파랑·보호 장치·톤은 그대로.
- 행렬: 빨강 행만 `R' = R + a·G − a/2·B` (이전 행렬 시안의 규칙: a 목표 = 빨강 평균이 초록의 0.8, 상한 1.0(블루워터 2.5), 빨강 하이라이트가 이미 있으면 끔).
- 검은점: 채널별 0.5% 값을 0으로 (STRONG 디헤이즈 0.45만큼 약하게).
- 흰점: 채널별 99.5% 값을 1로 (빨강 배율 ≥ 초록 배율).

| 이름 | 구성 |
|---|---|
| base | v1.16.1 그대로 |
| bgG | v1.16.1 + bgG |
| M1 | CCM만 (GPT 실험 A) |
| M2 | CCM + 검은점 (B) |
| M3 | CCM + 흰점 (C) |
| M4 | CCM + 검은점 + 흰점 (D) |
| M2p | M2인데 **보호·물 판정을 CCM 전 색으로** (아래 3장 발견 때문에 추가) |
| M2pg | M2p + 빨강 하이라이트 판정에서 흰 하이라이트 제외 |
각각 bgG OFF / ON 둘 다.

## 2. 결과 1 — 흰점(M3·M4)은 탈락 후보
| 문제 | 장면 |

| 모래·수영장 타일·물이 노랑·올리브로 | P7074850 수영장 바닥, DSC01282·DSC01478 모래, IMG_0048·101331 물빛 |
| 어두운 동굴 벽에 **빨간 점 노이즈** | OI000012 (빨강 배율을 초록 이상으로 맞추는 규칙이 어두운 빨강 노이즈를 키움) |
| 부채산호 과포화 | DSC01450 M4 |
- 클리핑은 크게 줄지만(중앙값 5.2 → 0.04%), 이는 흰점이 앞에서 밝기를 올려 톤 단계가 노출을 낮춘 결과다. 위 색 문제가 더 크다.
- 이전 행렬 시안의 "채널별 흰점 늘림 → 블루월 햇살 17% 클리핑"과 함께, **채널별 흰점은 이 형태로는 쓰지 않는 것**을 제안.

## 3. 결과 2 — 가장 중요한 발견: CCM을 물 판정 앞에 두면 물 판정이 무너진다
CCM이 빨강을 먼저 만들어 넣으면, 물 판정(빨강이 부족한 정도로 판정)이 물을 물로 못 본다.

| 사진 | 물 판정 평균 base | M2 (판정을 CCM 뒤 색으로) | M2p (판정을 CCM 전 색으로) |
|---|---|---|---|
| OI000249 블루워터 | 1.00 | **0.49** | 1.00 |
| 232212 초록 탁한 물 | 1.00 | **0.56** | 1.00 |
| IMG_0048 | 0.93 | **0.58** | 0.93 |
| 174948 | 0.88 | **0.18** | 0.88 |
| 29장 중앙값 | 0.76 | 0.54 | 0.76 |

- M1·M2가 Dive+에 더 가까워 보이던 것(Dive+ 거리 평균 28.7 → 25.5)은 **행렬 효과보다 물 판정이 무너져 초록→파랑·빨강 감쇠가 덜 걸린 효과가 크다.** 판정을 CCM 전 색으로 고친 M2p는 거리 28.5로 base와 거의 같다.
- 판정이 무너진 M2는 OI000249 거북·232212 다이버를 Dive+처럼 따뜻하게 만들지만, 225438 얼굴·탁한 물이 올리브·누렇게 되고 174948 전체가 누런 돌밭이 된다.
- 셰이더에서는 판정을 CCM 전 값으로 하는 것이 비용 0이다(원본 값을 이미 읽음). **CCM을 쓴다면 판정은 CCM 전 값으로** 해야 한다.

## 4. 결과 3 — 판정을 바로 잡으면(M2p) CCM 효과는 대부분 상쇄된다
- M2p에서 블루워터·초록 탁한 물 장면(OI000249, 232212, 225438, PB093507)은 base와 거의 같은 차가운 연보라·파랑으로 돌아간다. 뒤쪽 물 대상 단계(초록→파랑, 색온도 물 감쇠, 화이트밸런스의 중립 목표)가 CCM이 넣은 빨강을 다시 중립·파랑으로 돌리기 때문.
- M2p가 base와 확실히 다른 곳은 비물 피사체: DSC01282 모래(b* +12.8 → +23.1, 따뜻하지만 Dive+보다 노람), DSC01478·DSC01450 산호(주황 강해짐), 0830 산호.
- 중립 물체(GPT 조건 ②): 원본 C* → base → M2p+bgG
  - DSC01490 잠수복 16.8 → 7.6 → 5.9 (조금 더 중립, 강제 회색은 아님)
  - P1177088 흰 모래 구름 16.9 → 12.7 → 12.3 (거의 같음)
  - IMG_0033 탱크 21.7 → 24.6 → 24.4 (파란 기 그대로)
  - P7134924 흰 선베드 74.0 → 36.5 → 44.7 (**더 파래짐**, 회귀)
- 0689·183450: 행렬 빨강 계수 a = 0. 0689는 수면 흰 하이라이트를 "빨강 하이라이트"로 보고 꺼지고(흰 하이라이트 제외 판정으로 고치면 a = 0.14), 183450은 이미 빨강이 초록의 0.8 이상이라 행렬이 할 일이 없다. → **0689 금빛·해초 바닥 따뜻함은 이 CCM으로 안 나온다.**

## 5. bgG × CCM 상호작용 (GPT 2×2)
- 판정을 CCM 전 값으로 하면(M2p) 둘은 대체로 **더해지는 관계**: 상호작용 크기(ΔE) 0689 1.1(bgG 단독 12.2), 174948 1.3(4.8), 나머지 0.6 이하.
- 판정을 CCM 뒤 값으로 하면(M2) bgG가 아예 의미 없어짐(물 판정이 이미 무너져서).

## 6. 결론과 제안 (미확정)
1. **채널별 흰점: 이 형태로는 쓰지 않음** (노랑·올리브, 어두운 곳 빨간 점).
2. **CCM은 보호·물 판정을 CCM 전 값으로** — 아니면 물 판정이 무너진다. 이건 CCM 채택 여부와 무관하게 앞으로의 원칙으로 제안.
3. 판정을 바로 잡은 CCM(M2p)은 비물 피사체(모래·산호)를 따뜻하게 하지만, **STRONG의 핵심 문제(블루워터·탁한 물의 연보라·차가움, 0689 금빛, 해초 바닥)는 거의 못 바꾼다.** 원인은 빨강을 만드는 방식(rc vs 행렬)이 아니라 **물 대상 단계의 목표**(초록→파랑 강도 wp 1.0, 화이트밸런스가 물까지 중립으로 끄는 정도)에 있다. Dive+는 물을 청록으로 남기고 피사체만 데운다.
4. 다음 실험 제안(하나씩): **STRONG의 물 목표 실험** — ① 초록→파랑 강도(wp 1.0 → 0.5·0.0, bgG ON) ② 화이트밸런스 중립 목표에서 물 픽셀 비중 낮추기. CCM은 이 결과를 본 뒤 다시 판단(빨강 복원 상한 실험과 함께).
5. 검은점(M2)은 탁한 물에서 올리브를 줄이는 효과가 보였지만, 판정 수정 후(M2p)에는 차이가 작다. 보류.
