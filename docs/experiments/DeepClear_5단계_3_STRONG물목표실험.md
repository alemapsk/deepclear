## 3. 핵심: 초록→파랑 강도는 장면마다 맞는 값이 다르다
물 영역 a*/b* (a* 음수 = 초록, 양수 = 마젠타)

- **초록이 강한 탁한 물**: 지금(wp 1.0)은 중립을 넘어 마젠타(연보라)까지 간다. wp를 낮추면 Dive+ 방향(청록 유지)으로 가지만, wp 0도 Dive+만큼 청록은 아니고 회올리브.
- **약간 청록인 열린 물(0689)**: Dive+는 파랑으로 보내고, 지금 wp 1.0이 가장 가깝다. wp를 낮추면 청록이 돌아와 나빠진다(3단계에서 "전역 끄기 기각"과 같은 결과).
- Dive+는 두 경우 모두 **원본 물의 초록(a*)을 대략 절반만 줄이고 넘어가지 않는다** (232212 −36 → −16.5, 225438 −28.7 → −11.1, 0689 −11.9 → +0.1). DeepClear wp 1.0은 많이 초록인 물에서 넘어간다.
- 분석기의 물 초록 정도(gc, mwG/mwB)로는 두 장면을 못 가른다: 232212 0.96, 0689 0.93. 차이는 G/B가 아니라 빨강 부족(a*) 쪽.
- 피사체 영향: wp를 낮추면 모래(DSC01282 b* 12.9 → 18.8, Dive+ 19.1)·흰 모래 구름이 따뜻해지고, 흰 선베드는 덜 파래짐(C* 감소). 0689 거북은 bgG 덕에 이미 영향 없음.
- bgG OFF로 같은 wp.5를 돌려도(wp.5_off) 0689를 빼면 결과 차이 작음 → bgG와 wp는 대체로 독립.
- Dive+ 거리 평균: 기준 28.6 → wp.5 27.6 → wp0 28.6. 고정값 하나로는 전체가 좋아지지 않음.

## 4. 결론과 제안 (미확정)
1. **고정된 wp 값 하나로는 안 된다.** 많이 초록인 물엔 낮게, 약간 청록인 물엔 높게가 맞다.
2. 다음 후보는 "세기"가 아니라 **"목표"로 바꾸는 방식**: 초록→파랑이 물의 초록(a*)을 원본의 일정 비율(예: 절반)까지만 줄이고 마젠타로 넘어가지 않게 상한을 둔다. 계산은 픽셀의 g−b 초과분에 상한을 거는 형태로, 기존 값만 쓰고 추가 읽기 없음. 이것을 다음 실험으로 제안.
3. 물 마젠타 틴트 감쇠(tint)는 작지만 방향이 맞음 → 2번과 함께 볼 보조 후보.
4. 물 파랑 감소 감쇠(blue)는 탈락 후보.
5. 183450 해초 바닥은 세 손잡이 모두 거의 변화 없음(물 판정이 낮아 물 대상 단계가 거의 안 걸림) → 해초 바닥의 차가움은 물 목표 문제가 아님. 빨강 복원 상한 실험에서 다시 봄.
